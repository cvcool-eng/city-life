# City Life

An 8-bit top-down game: you're a homeless guy in a randomly generated New York–style city.
Dig through trash, sell and trade junk with people, take construction jobs, buy supplies at
Home Depot and build houses — until you can build a home of your own. Watch out for the cops.

**Play:** open `index.html` in a browser (or visit the GitHub Pages site).

| Key | Action |
| --- | --- |
| W A S D | Move |
| Shift | Run |
| E | Search trash / talk & trade / enter shops |
| Hold E | Build at your job's lot |
| 1–0 | Use junk inventory slots |
| M | City map |
| Esc | Close menus |
